# 验收与审查清单

交付前自查、或审查别人的界面时逐项过。报告问题时引用具体元素和数值，并给出改法。桌面（≥ 1024px，常用 1280×800 与 1440/1920 宽）和移动端（375–430 宽）分开检查；必要时测一个矮屏（如 376×640）。

## 层级与材质

- [ ] 内容层（卡片、表格、表单、列表）没有用 Liquid Glass（`.lg-*`）。
- [ ] 玻璃元素内部没有再嵌套带 `backdrop-filter` 的元素。
- [ ] 背景是静态纯色，没有渐变光、噪点、动画。
- [ ] 同屏 Liquid Glass ≤ 5 个，`backdrop-filter` 元素总数 ≤ 8 个。
- [ ] 表格和长文本用 `.mat-thick` 或实色；指标卡、图表用 `.mat-regular`。
- [ ] 弹窗是磨砂（半透明 + 大模糊），遮罩 30% 黑且不模糊。
- [ ] 顶栏没有整条实色背景，有顶部 scroll edge；底部 Tab Bar 下方没有发雾的压暗层。

## 颜色

- [ ] 每个视图最多一个强调色主按钮。
- [ ] 彩色只用于语义（成功 / 警告 / 错误 / 信息）和图表；没有装饰性彩色大底。
- [ ] 非状态类标签（类型、套餐）用中性色。
- [ ] 状态不只靠颜色：徽标带文字或图标。
- [ ] 填充用白色透明度，不是灰色透明度。
- [ ] 正文对比度 ≥ 4.5:1；`label-tertiary` 只用于非关键信息。

## 字体

- [ ] 没有小于 11px 的文字。
- [ ] 字重只有 400 / 500 / 600 / 700。
- [ ] 数字（表格数值列、KPI、金额、计数、分页）是等宽 + `tabular-nums`。
- [ ] 分组小标题没有用「全大写 + 宽字距」。
- [ ] 移动端输入控件字号 ≥ 16px。

## 形状与尺寸

- [ ] 圆角遵循同心规则；按钮、徽标、分段控件、搜索框、Tab Bar 是胶囊。
- [ ] 按钮、输入框高度来自 `--control-h-*`，同尺寸并排时上下对齐。
- [ ] 移动端可点击元素热区 ≥ 44×44；图标按钮都有 `aria-label`。

## 组件行为

- [ ] 按钮和卡片没有 hover 上浮 / 投影变化；按钮按下有 0.97 缩放。
- [ ] 删除入口用 destructive-soft，最终确认才用 destructive 实底；破坏性按钮不是默认按钮。
- [ ] 不可撤销操作的确认弹窗在代码里真的实现了，而不是只留一个回调。
- [ ] 立即生效用 Switch，保存后生效用 Checkbox。
- [ ] 表单错误文字替换说明文字，焦点 / 错误用外环、不改变尺寸。
- [ ] Select 选中项只在左侧打勾，不整行着色；filter 胶囊选中后变实线并显示值。
- [ ] 移动端配置类弹窗变成底部 Sheet；提醒类居中。
- [ ] 弹窗可用 Esc / 点遮罩关闭，关闭后焦点回到触发按钮。
- [ ] 移动端 HoverDetails 锚定在点击元素旁，不是底部抽屉。

## 布局

- [ ] 页面没有横向滚动（整页和表格容器都量过 `scrollWidth`）。
- [ ] 内容少时页脚在底部；整页高度的页面撑满视口。
- [ ] 表格页：表格卡片撑满剩余高度、内部滚动、表头吸顶、操作列固定右侧。
- [ ] 工具条控件没有重叠；汇总信息在下一行摘要里。
- [ ] 并排卡片等高，长列表不撑高整行；卡片里没有大块空白。
- [ ] 卡片里名称不被标签挤到截断；成对数值拆成主值 + 次值。
- [ ] 移动端筛选区不吸顶、不套方框；只有一个悬浮按钮，且不遮挡最后一项。
- [ ] 胶囊 Tab Bar 在宽屏手机上居中；滚动收起 / 点击展开正常。
- [ ] 没有内容的地方不能被滚动（独立页收起状态等）。

## 无障碍与降级

- [ ] 开启「降低透明度」后所有页面可用，材质变为实色，没有透明元素叠在一起。
- [ ] 开启「增强对比度」后分隔线和次要文字变亮。
- [ ] 开启「减弱动态效果」后只剩淡入淡出。
- [ ] Safari / Firefox 上玻璃是完整的 CSS 版本，没有因为折射失效而变透明。

## 工程

- [ ] 组件里没有 `bg-[hsl(var(--…))]` 之类任意值写法，没有 `text-[<11px]`，没有 `dark:` 前缀（单一深色主题）。
- [ ] 新增的颜色 / 字号 / 圆角都是 token，并已注册到 tailwind-merge。
- [ ] 改了带存储的默认值（列宽等）时升级了存储 key 的版本。
