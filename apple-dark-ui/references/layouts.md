# 布局：外壳、导航、页面模板

断点：**≥ 1024px 桌面布局（侧边栏），< 1024px 移动布局（底部胶囊 Tab Bar）**。功能一致，只是入口组织方式不同（HIG：根据可用空间切换 Tab Bar 与侧边栏）。

## 1. 导航的两条原则

1. **控件浮动，不铺整条背景。** 侧边栏、顶栏、Tab Bar 都是悬浮的玻璃块，内容可以从它们下方滚过；不用一整条实色顶栏把页面切成两段。
2. **用 scroll edge effect 代替分隔线。** 内容滚到浮动控件下方时，边缘逐渐模糊、压暗，既保证控件可读，又让人感觉到下面还有内容。

## 2. 桌面外壳

```
┌──────────┬──────────────────────────────────────────────┐
│          │  ⌕ 搜索…  ⌘K                     [账户 · 语言] │ ← 浮动玻璃控件组（无整条背景）
│ Sidebar  │  ─ scroll edge effect ─────────────────────── │
│ (浮动    │  Large Title                        [主操作]   │
│  玻璃)   │  描述                                          │
│          │  ┌ Card ─┐ ┌ Card ─┐ ┌ Card ─┐                 │
│          │  ┌ Table（mat-thick）───────────────────────┐  │
└──────────┴──────────────────────────────────────────────┘
        纯色背景 L0 贯穿整个窗口，包括侧边栏下方
```

### 侧边栏

- 宽 280，距窗口边缘 16 浮动，圆角 R-shell 24，上下各留 16、撑满高度，Liquid Glass regular。
- 结构：品牌区 → 导航分组 → 底部账户。
  - 品牌区：内边距 24，Logo 40（圆角 16），名称 16 / 600，下方一行版本号或副标题；底部一条分隔线。
  - 导航区：分组之间间距 32；分组标题 11 / 600、`label-tertiary`，不全大写、不加宽字距。
  - 菜单项：14 / 500、高 44、内边距 12、图标 16、图标与文字间距 12、项之间间距 4，**胶囊形**。
- 层级最多 2 层；带子项的节点用展开箭头（disclosure）。
- 选中项：「凸起玻璃片」（见 materials.md）+ `label-primary` 文字 + tint 图标。不要左侧发光竖条。
- 未选中：`label-secondary`；hover `fill-4`。
- 材质由外壳提供，侧边栏组件只负责内容，方便在平板抽屉（`.lg-thick` Sheet）里复用。

### 顶栏（工具栏）

- 不用整条背景，绝对定位浮在内容之上，距顶 16：左侧搜索胶囊（`glass` 按钮，「搜索… ⌘K」）；右侧一个玻璃胶囊组（账户名在宽屏显示、语言切换等）。
- 每组最多 3 个控件。
- 内容区顶部放 `.scroll-edge-top`（高度 = 顶栏所占高度，约 84），内容区 `padding-top` 同高。

### 内容区网格

内容区用「内容 + 页脚」两行网格：

```css
.app-content-grid {
  display: grid;
  min-height: 100%;
  grid-template-columns: minmax(0, 1fr);   /* 必须显式限制，否则宽表格会把整页撑宽 */
  grid-template-rows: minmax(0, 1fr) auto; /* 内容少时页脚贴底 */
}
/* 页面根元素是 h-full（工作台、表格内部滚动的列表页）时，网格固定为视口高度 */
.app-content-grid:has(> .app-content > :is(.h-full, .lg\:h-full)) { height: 100%; }
```

页脚（版权、版本、外链）放在滚动内容最底部，不常驻占视口。

## 3. 移动端外壳

```
┌──────────────────────────┐
│ ░ status bar / safe-area │
│ (◉)          (⌕)(🌐)(👤) │ ← 左：App 图标；右：搜索、语言、头像（40 圆形玻璃）
│ Large Title              │ ← 顶部 scroll edge effect
│ [搜索…………]  (↻)         │ ← 筛选区，不吸顶，随内容滚走
│ ┌ Item card ───────────┐ │
│ └──────────────────────┘ │   内容从 Tab Bar 下方穿过
│                    (+)   │ ← 56 悬浮添加按钮
│  ╭──────────────────────╮│
│  │ (◉)  ◎   ◎   ◎   ⋯   ││ ← 胶囊 Tab Bar（lg-clear）
│  ╰──────────────────────╯│
└──────────────────────────┘
```

- **顶栏**：不铺背景。左上角 App 图标（玻璃圆 + 透明底 Logo，点击回首页）；右上角三个 40 的圆形玻璃按钮。顶部 `.scroll-edge-top`，高度加上 `env(safe-area-inset-top)`。
- **顶栏菜单**仿 iOS 原生工具栏菜单：按钮本身变形成菜单（见 materials.md「形状变化」）；打开后焦点移到第一项，Esc 或点外部关闭，焦点回到按钮。
- **列表**：每项一张卡片（`mat-regular`、R-card 20、内边距 16、间距 12）。信息量大的列表项（键值网格 + 操作行）不必改成 iOS inset grouped 列表。
- **弹窗**：配置类自动变底部 Sheet，提醒类居中（见 components.md）。
- **键盘弹出**（聊天输入框聚焦）时隐藏 Tab Bar。
- **沉浸式页面**（聊天工作台、全屏编辑器）：不显示全局顶栏和 Tab Bar，左上角返回箭头 + 打开侧边抽屉的三横按钮。
- iOS 上锁住整页回弹（拦截不可滚动方向上的 touchmove），只让真正的滚动容器滚动。

## 4. 胶囊 Tab Bar

代码见 `assets/components/liquid-tab-bar.tsx` 与 `use-collapse-on-scroll.ts`。

- **位置**：距左、右、下各 21px（iOS 26 Tab Bar 的内缩距离）。底部在**浏览器标签页里**是 `env(safe-area-inset-bottom) + 21px`；在**主屏 PWA（standalone）里只留 21px**，不再叠加安全区——standalone 下页面铺满整屏，Home 指示条是叠在内容上的透明层，再加安全区会让胶囊离底边多出一截（见下方「PWA standalone」）。最宽 480，屏幕更宽时放进**居中的 480 列**里（`mx-auto w-full max-w-[480px]`）——只给胶囊设 `max-width` 而不居中，大屏安卓上会贴左。
- **尺寸**：高 62、胶囊形、Liquid Glass clear（Chromium 上真折射）。
- **选中块**：偏黑的胶囊（`black/40` + 内阴影），高 48、宽 48–60（比圆略向左右拉长；项多时自动收窄），上下与外框各留 6。不用实心强调色填充（玻璃上的颜色要克制）。
- **项目**：4 个主入口 +「更多」；图标 24、**只放图标、不放文字**。这是有意偏离 HIG（HIG 建议 Tab 带标签），补偿措施：每个 Tab 有 `aria-label` 与悬停提示、图标含义明确、「更多」菜单里的条目显示文字。
- **切换动效**（仿 iOS）：选中块沿弹簧曲线（420ms `cubic-bezier(.34,1.4,.64,1)`）滑到新位置，途中横向拉伸到 1.32 倍再回弹；新选中的图标弹跳一次（0.8 → 1.14 → 1）。reduced-motion 时直接切换。
- **滚动收起**：主内容向下滚动超过 6px 时收起为**左侧一个圆形图标**（宽度过渡到 62，只保留当前项，不显示选中块）；**向上滚动不恢复**（避免短距离回看时反复伸缩）；只有滚回顶部 24px 内或点一下收起后的图标才展开。收起状态下点击只负责展开，不触发跳转。
- **「更多」**：入口多于 5 个时必须保留。可以用沿弧线向上依次弹出的玻璃胶囊菜单（错开 18ms、离按钮越远向左偏移越多、轻微旋转），每项高 44、文字 + 图标；菜单下方 25% 黑遮罩，点遮罩或 Esc 关闭。当前页面在「更多」里时，该 Tab 显示对应页面的图标。
- **Tab Bar 下方不加模糊 / 压暗层**（见 materials.md「Scroll edge effect」）。
- 搜索放在顶栏右上角，Tab Bar 旁不另放搜索岛。

### PWA standalone

启动时判断是否以主屏应用运行，并在 `<html>` 上打标记：

```ts
export function isStandalone() {
  const nav = window.navigator as Navigator & { standalone?: boolean }
  return nav.standalone === true
    || matchMedia('(display-mode: standalone)').matches
    || matchMedia('(display-mode: fullscreen)').matches
}
// 应用启动、resize、orientationchange、pageshow 时同步一次
document.documentElement.dataset.standalone = isStandalone() ? 'true' : ''
```

```css
/* 应用根高度：浏览器里用 100dvh；standalone 里用 100vh——
   iOS 主屏应用冷启动时 100dvh / innerHeight 会比真实屏幕矮约一个 safe-area-inset-top */
#root { height: var(--app-viewport-height, 100dvh); }
html[data-standalone='true'] { --app-viewport-height: 100vh; }

/* 底部内缩：浏览器 = 安全区 + 21px；standalone = 21px */
.tabbar-shell { padding-bottom: calc(env(safe-area-inset-bottom, 0px) + 21px); }
html[data-standalone='true'] .tabbar-shell { padding-bottom: 21px; }

/* 主滚动区底部留白同理：浏览器 = 安全区 + 6rem；standalone = 6rem */
.main-scroll { padding-bottom: calc(env(safe-area-inset-bottom, 0px) + 6rem); }
html[data-standalone='true'] .main-scroll { padding-bottom: 6rem; }
```

软键盘弹出时（`visualViewport.height` 明显小于窗口高度）改用 `visualViewport.height` 作为根高度，避免内容被键盘盖住。`index.html` 的 viewport 要带 `viewport-fit=cover`，否则 `env(safe-area-inset-*)` 一直是 0。

## 5. 页面标题与大标题收起

- 页面顶部是 PageHeader：小号上级分类（eyebrow，Footnote `label-3`）→ Large Title（随内容滚动）→ 描述（Body `label-2`）；右侧主操作按钮（每页最多 1 个 tint）+ 次要按钮。移动端主操作改成悬浮添加按钮或图标按钮。
- **大标题收起**：滚动越过标题后，工具栏里淡入小号 Headline 标题——大标题底边滚到距顶约 72 以内时，行内标题从下方 4px 上移淡入（200ms）。用 IntersectionObserver 实现，每页只开一个。桌面行内标题居中；移动端右侧有三个按钮，居中放不下，改为紧跟 Logo 左对齐、过长截断。
- 移动端 Large Title 34px 左对齐。

## 6. 页面模板

先盘点项目里真实存在的页面结构，再归类。以下是中后台最常见的六类，每类给出桌面 / 移动端的排法。

### 表格列表页

- **桌面**：PageHeader → 工具条行（左：搜索框（宽约 208）+ 分段控件或 filter 胶囊；右：secondary 次要操作 + 主按钮）→ `.mat-thick` 卡片中的表格 → 分页。页面固定为视口高度，表格卡片撑满剩余空间、内部滚动、表头吸顶、操作列固定右侧。
- 工具条放不下时先挪走非筛选元素（例如把「复制接口地址」这类信息胶囊挪到标题右侧），再考虑换行；不允许控件互相重叠。
- 结果汇总（总数、合计金额等）放在工具条下一行的小字摘要里，右侧放「清空筛选」。
- **移动端**：筛选区（见第 7 节）→ 每项一张卡片（名称独占标题行；标签换行；2–3 列键值；底部图标按钮行）→ 右下 56 悬浮添加按钮。

### 卡片分组页

适合每项信息丰富、需要进度条或多个状态的对象（账号、设备、实例）。

- 工具条：搜索 + 类别横条（只列出已有的类别）+ 状态 filter（紧跟在横条后）+ 右侧操作。
- 按类别分组、可折叠；组标题是 Headline + 数量（`label-3`），不带底色；出错的项单独成组放最后。
- 卡片网格桌面 2 列；卡片内：标题行（图标 36 + 名称 Headline + 中性标签；下一行状态徽标 + 副标题）→ 固定 3×2 指标网格 → 进度 / 额度 → 底部图标操作行（`border-t` 分隔，删除用 `text-danger`）。
- 移动端单列，指标网格改 2 列；导入等次要操作放进筛选区的圆形图标按钮，不要叠两个悬浮按钮。

### 筛选栏 + 展开卡片页

左侧约 248 的筛选栏（plain 列表：类别 / 来源 / 排序，带计数胶囊）+ 右侧可展开的卡片列表，两栏各自滚动。移动端筛选栏改为筛选区里的 filter 胶囊。

### 仪表盘

- 概览：PageHeader（右侧更新时间 + 刷新）→ 一排指标卡（3–4 张）→ 若干行双栏卡片。
- **双栏卡片等高**：并排的两张卡片，行高应由「内容高度固定」的那张决定（例如系统资源卡），列表类卡片（可能很长）不要撑高整行：把它放在 `relative` 格子里并 `absolute inset-0` 填满，内部滚动；单列时给一个最大高度（如 480）。
- 卡片高度有余量时，让内容铺满（分隔线田字格、指标区 `flex-1`），不要在卡片下半部留大块空白；指标之间用发丝线分隔，不要给每个指标再加一层底色。
- 分析页：筛选行 → KPI → 趋势（3/4）+ 排行（1/4）→ 两个半宽图表；移动端单列，KPI 两列。
- 图表维度切换用分段控件（图标或文字），不要用下拉。

### 设置页

PageHeader → 分隔线 → 左侧约 220 的二级导航（移动端改下拉）+ 表单内容（宽 ≤ 896，不用卡片：Headline 小节标题 + 分隔线、两列字段、底部靠左的保存 / 重置）。单页设置省略二级导航。

### 工作台（聊天、编辑器）

无 PageHeader；左侧约 264 的会话栏（模式分段控件 + 新建 + 胶囊形会话列表，选中项用凸起玻璃片）+ 顶部工具行 + 主区域 + 底部浮起的输入框。

**输入框**：不是平涂填充，而是一块微微浮起的面板——底色比背景亮一档、叠顶光、描边顶边亮往下变暗、下方柔和投影；聚焦时描边整体提亮并加一圈强调色外环。圆角约 26、宽 ≤ 768。左下「+」附件菜单（照片 / 拍照（仅触屏）/ 文件），右下模型与参数选择（小卡片：一整块可点区域，点开后换成模型列表）。

移动端：独占整屏，左上返回 + 会话抽屉（Sheet 左侧），无全局顶栏与 Tab Bar。

## 7. 移动端筛选区

列表页移动端的筛选区**不吸顶、不套方框**，直接排在标题下面并随内容滚走。由上到下：

1. **搜索 + 圆形图标按钮**：搜索框 `rounded-full` 带放大镜图标，右侧 1–2 个 40 / 44 的圆形 secondary 图标按钮（刷新、排序、保存、更多筛选），有隐藏筛选生效时按钮右上角加一个小圆点。
2. **分类横条**：只有一个分类维度时用与桌面相同的分段横条，可横向滑动、右侧渐隐。
3. **筛选胶囊**：有多个维度时每个维度一枚 filter 下拉胶囊，排成一行可横向滑动，左右延伸到屏幕边缘、右侧渐隐、末尾留白；需要两个输入的维度（时间范围）做成一枚胶囊，点开抽屉选择。
4. **摘要行**：「共 N 条」或一行汇总小字（数值保留语义色），右侧「清除筛选」文字按钮。

不要做成顶部 Tabs + 搜索类型切换那种复杂结构，除非产品真的有多种搜索模式。

## 8. 独立页（登录、注册、404）

- 一个沉浸式背景场景（静态或极缓慢、不影响玻璃的装饰）+ 字标与一句标语 + 一个入口按钮；点按钮后表单卡片（Liquid Glass thick、分组输入）从下方升起，卡片右上角关闭按钮把它收回成按钮。
- 移动端收起时字标在画面中央、入口按钮靠下；**展开时字标只略微上移、停在卡片上方**，装饰元素保持在字标上方的空间里，不要因为表单出现就把整个画面重新排一遍。矮屏放不下时字标再继续上移。
- 收起时卡片必须被裁掉（`overflow: hidden`），否则 0 高度的网格行里溢出的卡片会撑出可滚动高度，页面能被往上推（见 pitfalls）。
- 卡片宽 ≤ 400；输入框分组成一块（上下两个字段共用一个圆角容器，中间发丝线）。
